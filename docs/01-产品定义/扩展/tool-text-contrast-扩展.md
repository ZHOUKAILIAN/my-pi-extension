# Tool Text Contrast 扩展

状态：`DECIDED`

本扩展修复 Pi 内置 `read`、`write` 工具卡片中未设置前景色的正文随终端默认字色显示、与 Pi 主题背景失配的问题。它是独立可启用、移除的显示兼容扩展，不属于 Subagent 或 Workflow。

## 行为与边界

- 未着色正文使用当前 Pi 主题的正文前景色，不依赖终端默认字色；浅色和深色主题均适用。
- 保留已有语法高亮、粗体、链接、换行、工具卡片背景、折叠与展开行为。
- 不修改工具参数、执行、结果数据、会话持久化或模型上下文；其他工具不受影响。
- 主题切换、部分参数流式更新、结果更新及组件缓存复用后仍采用当前主题。
- 使用 Pi 公共 renderer 扩展 API；不覆写全局 Pi 安装文件、不替换工具执行器。可通过移除该扩展回退。

## 验收

1. `write plan.md` 的中文标题、段落、列表、行内代码和代码块在浅色卡片上可读；深色主题对应成立。
2. `read` 的同根高亮路径与纯文本路径均保持主题字色；已有高亮颜色不被统一涂掉。
3. 成功、失败、运行中、展开/折叠、窄宽换行和主题切换均不丢文字、不改变布局或背景。
4. 扩展通过宿主真实加载；与原 renderer 的可见文字及工具执行定义一致。
5. 支持版本与实际验证范围由 [L2 技术说明](../../02-产品实现/tool-text-contrast-技术设计.md)集中记录。
