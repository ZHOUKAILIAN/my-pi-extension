- L1 Core 只定义共享产品语义；L1 Extension 只定义入口特有产品流程。
- L1 上下文摘要是派生产物，不是第二套真理源。
- L2 文档描述实现机制和当前事实；源码与测试优先于实现摘要。
- L3 只拥有目录、package、构建、安装、发布和项目默认。
- 单个文件出现多个主要层级责任时，应拆分后再写回。
